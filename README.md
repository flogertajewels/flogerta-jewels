# Flogerta Jewels — Mockup-inspired landing page

Open `index.html` directly in a browser to preview.

## Files
- `index.html` — complete responsive landing page
- `logo.png` — your supplied FJ diamond artwork, cropped only to remove excess outer margin

## Copyright / assets
No external stock images, fonts, libraries, or copied website assets are used.
The jewellery artwork in the hero is drawn with CSS.

## Logo
The supplied FJ-inside-diamond artwork is preserved as the brand mark. The website pairs it with a horizontal FLOGERTA / JEWELS wordmark for the header.

## GitHub Pages
Upload `index.html` and `logo.png` to the root of a GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → / (root).
